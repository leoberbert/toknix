Toknix for Windows x86_64

Rust is not required. Extract this archive and run toknix.exe.

Opening toknix.exe from Explorer starts the dashboard and the browser.
It does not leave a command window open. Run it again to reopen the page.

From PowerShell or Command Prompt, the same program prints the address
and Ctrl+C stops the server. The page stays on this computer, at
http://127.0.0.1:4780 unless another program already holds that port.

Toknix para Windows x86_64

Esta versão não exige Rust. Extraia este arquivo e execute toknix.exe.

Abrir o toknix.exe pelo Explorer inicia o painel e o navegador. Nenhuma
janela de comando fica aberta. Execute de novo para reabrir a página.

No PowerShell ou no Prompt de Comando, o mesmo programa mostra o endereço
e Ctrl+C encerra o servidor. A página fica neste computador, em
http://127.0.0.1:4780, salvo se outro programa já estiver nessa porta.
