Toknix for Linux x86_64

Rust is not required. This AppImage needs glibc from Ubuntu 24.04 or a
newer distribution, such as current Fedora. If it does not start, run:

    ./toknix-*.AppImage --appimage-extract-and-run

Mark the file executable and run it. Toknix opens the dashboard in the
browser and serves it on http://127.0.0.1:4780. From a terminal, Ctrl+C
stops the server.
